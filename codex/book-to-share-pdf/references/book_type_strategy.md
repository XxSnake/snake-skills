# Book Type Strategy

本文件规定不同类型书籍的拆解方式与表达策略。

核心原则：

> 不是每本书都应该按章节复述。先判断这本书的传播力量来自哪里，再决定怎么讲。

## 1. 思想哲学型

### 典型特征

- 讨论存在、自由、伦理、意义、真理、现代性、主体性等抽象问题
- 概念密度高
- 原文可能难读
- 传播点通常不是“知识点”，而是“问题感”和“精神冲突”

### 适合的表达策略

优先使用：冲突型、问题型、观点型。

### 拆解重点

必须抓住：作者面对的根本问题、这个问题为什么让人困扰、作者反对什么、作者提出了什么新看法、这个看法与普通人有什么关系。

### 不适合的讲法

避免按章节复述、堆概念名词、把哲学讲成鸡汤、把复杂争论简化成“人生建议”。

### 推荐结构

```text
一个现代人的困境 -> 作者看到的矛盾 -> 传统答案为什么不够 -> 作者给出的新视角 -> 这个视角对今天的意义
```

## 2. 社科洞察型

### 典型特征

- 解释社会结构、制度、阶层、权力、组织、城市、教育、消费等问题
- 通常有现实解释力
- 读者关心“这和我有什么关系”

### 适合的表达策略

优先使用：问题型、冲突型、案例型。

### 拆解重点

必须抓住：这本书解释什么社会现象、作者反对的常识是什么、背后的结构性机制是什么、它改变了读者看现实的哪个角度、是否存在争议或立场偏向。

### 不适合的讲法

避免只讲结论不讲机制、把结构问题讲成个人努力问题、只罗列社会现象、把复杂问题讲成阴谋论。

### 推荐结构

```text
一个大家都熟悉的现象 -> 常见解释为什么不够 -> 作者给出的结构解释 -> 现实案例 -> 对个人理解现实的帮助
```

## 3. 历史叙事型

### 典型特征

- 以历史事件、时代变化、王朝兴衰、制度演变或人物群像为主
- 信息量大，容易变成流水账
- 传播力量来自因果、选择和命运感

### 适合的表达策略

优先使用：故事型、命运型、冲突型。

### 拆解重点

必须抓住：历史主线、关键转折点、改变结果的选择、作者如何解释因果、这本书和传统历史叙述有什么不同。

### 不适合的讲法

避免年表式堆事件、只讲人物八卦、把复杂历史归因于单个人、过度戏说。

### 推荐结构

```text
时代背景 -> 主要矛盾 -> 关键人物/制度选择 -> 转折点 -> 结果 -> 后果与余波
```

## 4. 商业管理型

### 典型特征

- 讨论公司、组织、战略、管理、增长、创新、决策
- 通常有方法论，容易被讲成培训课

### 适合的表达策略

优先使用：案例型、问题型、观点型。

### 拆解重点

必须抓住：作者解决的管理问题、方法论适用边界、案例是否充分、哪些观点适合迁移、哪些观点容易被误用。

### 不适合的讲法

避免把商业案例讲成成功学、只提口号不讲条件、忽略时代/行业/规模差异、把管理工具当万能公式。

### 推荐结构

```text
一个组织难题 -> 常见错误做法 -> 作者提出的框架 -> 案例说明 -> 适用边界 -> 对普通工作的启发
```

## 5. 人物传记型

### 典型特征

- 围绕一个人物的一生、职业、思想、作品或时代处境展开
- 传播力量来自人物选择、命运转折和时代关系

### 适合的表达策略

优先使用：命运型、故事型、冲突型。

### 拆解重点

必须抓住：传主真正的命运问题、他/她与时代的关系、关键选择和转折、传记作者的立场、是否存在美化、遮蔽或过度解释。

### 不适合的讲法

避免简历式流水账、把人物神化、只讲成败不讲处境、忽略复杂性。

### 推荐结构

```text
人物出场 -> 时代压力 -> 关键选择 -> 代价与成就 -> 复杂性 -> 这个人物今天为何仍值得讲
```

## 6. 文学小说型

### 典型特征

- 以人物、情节、语言、象征、主题为核心
- 不适合过度概括
- 拆解要保留文学的暧昧和余味

### 适合的表达策略

优先使用：故事型、命运型、冲突型。

### 拆解重点

必须抓住：表层故事、人物困境、主题、叙事方式、哪些地方不能被简单说破。

### 不适合的讲法

避免剧透式复述全文、把小说讲成道理、把人物简化成标签、用过度分析破坏阅读余味。

### 推荐结构

```text
一个人物/场景进入 -> 表层故事 -> 深层困境 -> 关键转折 -> 主题显影 -> 留下余味
```

## 7. 心理成长型

### 典型特征

- 关注自我理解、情绪、关系、创伤、习惯、人生选择
- 容易被讲成鸡汤或方法清单

### 适合的表达策略

优先使用：问题型、故事型、案例型。

### 拆解重点

必须抓住：它解决的心理问题、作者依据、方法专业边界、哪些内容对普通人有帮助、哪些内容不能替代专业治疗或咨询。

### 不适合的讲法

避免鸡汤化、过度承诺改变效果、把复杂心理问题简单归因、把书中建议当医疗或治疗建议。

### 推荐结构

```text
常见心理困境 -> 为什么常规理解不够 -> 作者的核心观点 -> 案例或练习 -> 适用边界 -> 对读者的温和提醒
```

## 8. 投资财经型

### 典型特征

- 讨论市场、财富、风险、周期、企业、资产配置、投资心理
- 容易被误解成投资建议

### 适合的表达策略

优先使用：问题型、案例型、观点型。

### 拆解重点

必须抓住：核心投资观、适用市场和时代背景、风险、作者立场或利益背景、哪些观点是原则而非具体操作。

### 不适合的讲法

避免给出具体买卖建议、把历史收益当未来承诺、忽略风险、把作者经验当普适规律。

### 推荐结构

```text
一个投资误区 -> 作者如何理解市场 -> 核心原则 -> 历史案例 -> 风险边界 -> 对普通投资者的认知启发
```

## 9. 文化评论型

### 典型特征

- 评论媒介、消费、审美、流行文化、技术、现代生活方式
- 通常具有批判性和时代感

### 适合的表达策略

优先使用：冲突型、观点型、问题型。

### 拆解重点

必须抓住：作者批评的对象、批评背后的价值标准、这本书回应的时代问题、今天是否仍然有效、时代局限。

### 不适合的讲法

避免只做情绪批判、把复杂文化现象道德化、用怀旧替代分析、忽略作者所处时代。

### 推荐结构

```text
一个日常文化现象 -> 作者的不安 -> 他如何解释这种变化 -> 这种变化带来的代价 -> 今天还能给我们什么提醒
```

## 10. 经典名著型

### 典型特征

- 影响时间长，解释传统多，容易被讲成标准答案
- 需要讲出“为什么今天还值得读”

### 适合的表达策略

视作品而定，可使用故事型、命运型、冲突型、问题型。

### 拆解重点

必须抓住：它为什么成为经典、历史上如何解释它、今天读它还能获得什么、哪些地方需要时代背景、哪些常见解读过于简化。

### 不适合的讲法

避免教科书式标准答案、只讲历史地位、用现代价值简单审判古典文本、忽略文本本身的复杂性。

### 推荐结构

```text
为什么它被称为经典 -> 现代读者的进入难点 -> 核心故事/问题 -> 经典性的来源 -> 今天重新读它的意义
```
