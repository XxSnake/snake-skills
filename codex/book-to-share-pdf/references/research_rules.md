# Research Rules

本文件规定只给书名时如何研究资料、判断可信度，以及资料不足时如何降级。

核心原则：

> 宁可明确资料不足，也不要写出看似完整、实际没有依据的拆书稿。

## 1. 研究目标

研究不是为了堆资料，而是为了支撑以下判断：

- 这本书是哪一本
- 作者是谁
- 它的写作背景是什么
- 它主要讲什么
- 它的结构如何
- 它最值得传播的观点是什么
- 它适合怎么讲
- 它有哪些争议、局限或误解
- 资料是否足够生成负责的分享 PDF

## 2. 优先资料来源

### 2.1 一级资料

最优先使用：原书全文、公版全文、官方授权全文、出版社试读、正规平台试读、目录、作者序言或后记、作者访谈、作者演讲、作者文章、出版社页面。

一级资料用于确认书名版本、作者观点、章节结构、核心论证和关键表述。

### 2.2 强二级资料

可用于补充理解：权威媒体书评、学术评论、专业期刊评论、大型出版社介绍、知名评论人文章、可靠播客访谈整理、大学课程书单或讲义中的介绍。

强二级资料用于判断作品影响、接受情况、争议点、时代背景和不同解读。

### 2.3 弱二级资料

谨慎使用：普通博客、平台笔记、自媒体摘要、短视频文案、未署名书摘、AI 生成疑似内容。

弱二级资料只能作为线索，不能作为关键事实依据。

### 2.4 读者评价

可以参考豆瓣、Goodreads、亚马逊、微信读书等平台的读者长评，用于判断普通读者共鸣点、误解点、阅读体验和传播角度。

不能用于确认作者原意、书中事实、学术结论或历史事实。

## 3. 搜索顺序

### Step 1: 识别书籍

```text
书名 作者 出版社
书名 原文名
书名 目录
书名 table of contents
```

确认是否存在同名书。

### Step 2: 找官方资料

```text
书名 出版社
书名 作者 访谈
书名 official
书名 publisher
```

目标：确认版本、简介、作者背景。

### Step 3: 找内容结构

```text
书名 目录
书名 试读
书名 excerpt
书名 preview
书名 introduction
书名 preface
```

目标：获得章节结构、序言、开头、核心段落。

### Step 4: 找高质量评论

```text
书名 书评
书名 review
书名 criticism
书名 analysis
书名 访谈
```

目标：理解主流评价、争议、影响。

### Step 5: 判断是否需要全文

如果资料不足，继续寻找合法全文或足量节选：

```text
书名 public domain
书名 full text legal
书名 archive official
书名 library preview
书名 open access
```

只使用合法可访问资料。

## 4. 资料充分性判断

### 高充分性

满足以下条件之一：已获得合法全文或公版全文；已获得足量章节、序言、目录、访谈和权威评论；书籍是经典作品，存在大量可靠研究和公开文本。

可标注：`资料充分性：高`。

### 中充分性

满足：有出版社简介、有目录或部分试读、有多篇可靠书评或访谈，能支撑主线和核心观点，但无法替代全文细读。

可标注：`资料充分性：中`。

### 低充分性

出现以下情况：只有电商简介、只有零散短评、无目录、无试读、无可靠长评、作者和版本信息不清。

必须标注：

```text
资料充分性：低
公开资料版拆解，尚不足以替代全文精读。
```

## 5. 置信度标签

PDF 中必须给出拆解置信度。

- 高：有全文或足量一级资料，核心观点可直接追溯，争议和局限可被交叉验证。
- 中：公开资料较充分，可负责任地讲清楚书的主线，但没有完整全文支持所有细节。
- 低：资料有限，只能做初步介绍，不应生成过度细致的章节分析。

## 6. 交叉验证规则

重要事实至少需要两个来源支持，或一个可靠一级来源支持。

必须交叉验证的信息：作者身份、出版年份、原书名、章节结构、核心论点、重大争议、销量/奖项/排名等容易变化或被夸大的信息。

无法验证时，使用保守表述：

```text
公开资料显示……
根据现有资料可以判断……
较稳妥的说法是……
目前资料不足以确认……
```

避免：

```text
毫无疑问……
必然……
作者真正想说的一定是……
所有人都认为……
```

## 7. 引用和摘录规则

- 可以使用少量短引文来增强质感，但不要大段复制。
- 默认用自己的话解释书的观点。
- 正文保持阅读流畅，资料来源集中列在 PDF 最后一节。
- 关键事实应能追溯到来源。

## 8. 资料不足时的降级流程

### 第一步：扩大搜索

换用原文书名、作者名、译名、出版社、ISBN、关键词、书中核心概念。

### 第二步：寻找合法文本

寻找公版全文、出版社试读、作者公开章节、图书馆预览、正规平台试看。

### 第三步：降低拆解粒度

不要写细节章节分析。改为书籍背景介绍、可确认中心主题、可确认观点、进一步精读方向和初步分享角度。

### 第四步：明确标注限制

PDF 中必须写：

```text
由于公开资料有限，本小册为公开资料版拆解，适合作为初步分享材料，不适合作为全文精读替代。
```

## 9. 不允许的做法

禁止编造章节内容、编造作者观点、编造书中案例、把读者评论当作原书内容、把营销简介当作完整论证、使用盗版全文作为默认资料、没有全文却假装全文精读、隐藏资料不足问题。
