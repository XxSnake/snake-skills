# Snake Digest Codex PDF 设计指南

## 视觉定位

关键词：泛黄纸张、轻杂志、读书会小册子、暖色水彩、克制的编辑排版。

不是：PPT、论文、白底 Word、花哨营销页。

## 页面气质

- 背景：米白、旧纸黄、浅赭色，不用纯白。
- 正文：深棕黑，避免纯黑。
- 装饰：细线、角标、淡色块、小型品牌标识。
- 插图：暖色调水彩/淡彩，与纸张背景统一。

## 封面

封面图竖版 9:16，满铺 A4。标题不宜超过两行。底部可用渐变遮罩承载标题。

封面元素：

- SNAKE DIGEST
- 主标题
- 副标题
- 日期 / 主题分类
- 二维码（如有）

## 正文

- 每页保留呼吸感，不要把文字塞满。
- 段落 2-5 行为宜。
- 长解释后插入 key-point 或 analogy-box。
- 每 2-3 个章节至少有一个视觉元素。

## 插图

插图必须来自 Codex 原生 Image2 生成的真实图片文件。不得用 SVG、Mermaid、程序绘图、占位图或截图替代。

图片占位符支持：

```html
<!--IMG:img_01:图片说明:normal-->
<!--IMG:img_02:图片说明:hero-->
<!--IMG:img_03:图片说明:small-->
```

- hero：适合章节转折或非常有画面感的故事。
- normal：默认正文插图。
- small：适合轻量类比或概念提示。

## 资料来源

PDF 最后应保留“资料来源与延伸阅读”。不要让读者觉得整篇内容没有出处。


## v3 视觉原则：低色块纸感统一

本设计系统要避免“PPT 色块感”。组件是阅读节奏，不是装饰主角。

- 所有卡片背景优先使用半透明纸色，不使用大面积实心黄、橙、蓝、绿、红。
- 数字卡、流程卡、重点框只能轻轻托出信息，不要比正文更抢眼。
- 正文图片默认 88%-92% 宽；hero 图最多一张，且不做负边距铺满。
- 代码块使用浅纸色边框，不使用深色背景。
- 页面整体应像一本泛黄纸张的小册子，而不是彩色信息图或商业 PPT。

## v4 页脚与文件名规则

- 正式 PDF 必须由 `scripts/merge_images.py` 或 `scripts/md_to_pdf.py` 通过 WeasyPrint 生成。
- 不要用 Chrome / Edge 打开 HTML 后“打印为 PDF”。浏览器默认页眉页脚可能显示 `file:///.../final.html`，并可能因为背景图形设置导致四周白边。
- 正文页脚左侧固定显示 `@潇潇蛇`。
- 正式交付文件名必须使用文章标题，例如 `路边零食店到底怎么赚钱.pdf`，不要保留为 `final.pdf`。
