# Snake Digest Codex

为零基础读者制作事实可靠、叙事清楚、插画统一的中文 PDF。默认暖色旧纸张、轻杂志风格；用户指定的受众、篇幅和视觉要求优先。

## 按任务推进

新建小册完成研究、写作、插画、合成与验收；已有小册的局部修改只重做受影响内容及检查。主题已明确就开始；只有缺失信息会改变结果且无法查明时才询问。整本书拆解使用 `book-to-share-pdf`。

在任务工作目录保存 `article.md`、`sources.md`、`image_plan.json`、`images/` 和渲染检查材料；最终 PDF 放在用户指定的交付目录。脚本示例见 [构建与验收](references/workflow_checklist.md)。

## 内容与来源

联网核实所需事实，优先官方、原始资料及可靠机构。记录来源链接、日期、支持的主张及限制。重要事实用一个可靠原始来源或两个独立可靠来源支持；没有证据时缩小结论，不补写细节。

按主题选择时间线、概念递进、人物或问题链等组织方式。用真实场景打开话题，术语先用白话解释，类比贴近主题；不固定开场句数、类比对象或章节数量。正文区分事实与推断，末尾列“资料来源与延伸阅读”，不混入命令或图片计划。

完成后的零基础读者应能说清核心机制、复述一个关键例子，并知道结论的适用边界。关键结论和数据必须能追溯到 `sources.md` 中的具体来源。

## 插画

规划图片时读取 [图片指南](references/image_prompt_guide.md)，采用 `templates/image_plan_template.json` 的字段。默认一张竖版封面和少量横版正文图，以帮助理解为准，用户指定数量时按请求执行。

使用内置 `image_gen`，遵循当前 `imagegen` 技能的调用方式，每个独立画面分别生成并检查。最终插画为 PNG/JPG/WebP 位图，不用 SVG、程序绘图、截图或占位图冒充生成插画。准确数据和文字关系放在正文或 HTML 组件中。

按工具实际返回路径复制选定图片到项目 `images/`，使用计划中的稳定文件名。内置工具不可用时说明阻碍并保留已完成材料，不静默切换到其他模型或需要密钥的路线；只有用户同意相应备用路线后才继续。验证脚本不能证明图片生成来源。

## 合成与完成

排版时读取 [PDF 设计指南](references/pdf_design_guide.md)，运行与本次纸张、风格和图片布局匹配的内容检查，再通过脚本的无界面引擎合成 PDF。保持图片计划、正文占位符与文件一致，确保来源记录完整。

新建 PDF 或缺少此前完整验收证据时，全部页面都需渲染并查看，检查中文、裁切、重叠、封面、页脚、分页和来源页。已有完整验收证据的局部修复可只复验受影响页面，同时确认其余页面未变；影响整体分页时扩大检查。不能把生成成功或自动检查通过说成视觉验收完成。

主要交付以文章标题命名的 PDF，说明实际完成情况和影响理解的限制。图片或渲染仍失败时保留合格的文章、图片及 HTML，明确最终 PDF 尚未完成。
